# BNPL Merchant Settlement Reconciliation

Reconcile buy-now-pay-later orders, fees, returns, and promotional subsidies to merchant settlement entitlement.

**Primary buyer:** Retailers and ecommerce merchants. **Evidence:** provider agreements, orders, installments, captures, cancellations, returns, merchant discount rates, promotions, disputes, settlements, and deposits.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Provider agreement library
- Order installment ingestion
- Capture completion matching
- Cancellation control
- Full return reconciliation
- Partial return allocation
- Merchant discount calculation
- Promotional subsidy calculation
- Consumer dispute allocation
- Reserve hold validation
- Settlement statement matching
- Missing deposit detection
- Provider correction workflow
- Cash reconciliation
- Provider channel analytics

Run `./start.sh`, then open <http://127.0.0.1:4669>. API: `5669`.
